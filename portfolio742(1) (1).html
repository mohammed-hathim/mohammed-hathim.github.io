Developed a hardware-software system for live electricity monitoring using the NodeMCU ESP8266 as the main microcontroller, paired with an ACS712 current sensor to capture real-time readings.
Engineered a real-time electricity monitoring system by configuring the NodeMCU ESP8266 as the central microcontroller, enabling continuous collection and processing of live power consumption data.
Integrated an ACS712 current sensor with the microcontroller to capture accurate current readings, converting raw sensor signals into meaningful electricity usage metrics.
Programmed the complete firmware in C/C++ to combine embedded systems logic with IoT connectivity, resulting in a functional hardware-software solution for live electricity tracking.
